Blinkit Sales Dashboard Analysis
📌 Overview

This project analyzes Blinkit sales data and presents key insights through an interactive dashboard. It helps in understanding sales performance, customer trends, and business growth.

🛠️ Tools Used

Python (Pandas, NumPy, Matplotlib, Seaborn)

Power BI

Excel

📊 Dashboard Highlights

Total sales overview

Category-wise and region-wise sales analysis

Customer purchase patterns

Time-based sales trends

🚀 How to Use

Clone this repository.

Open the Power BI file to view the dashboard.

Use Python notebooks for preprocessing and analysis.
